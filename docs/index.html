interface IPermitRepository {
  findByOwnerId(ownerId: UUID): Promise<BuildingPermit>;
  verifyOtpAndIssue(permitId: string, otp: string): Promise<PermitStatus>;
}

export class IssuePermitUseCase {
  constructor(
    private readonly permitRepo: IPermitRepository,
    private readonly authGuard: SanctumJwtAuth,
    private readonly otpService: OtpVerificationService
  ) {}

  async execute(command: IssuePermitCommand): Promise<Result> {
    // 1. Enforce SOLID: Dependency Inversion
    const isValidOtp = await this.otpService.verify(command.phone, command.otp);
    if (!isValidOtp) throw new InvalidOtpException();

    // 2. PostgreSQL Atomic Transaction
    return await this.permitRepo.verifyOtpAndIssue(command.permitId, command.otp);
  }
}

Architectural Expertise

Clean Architecture & SOLID Principles

Building maintainable software by decoupling business rules from external libraries, user interfaces, and database drivers.

Clean Architecture

Applied in enterprise projects like رخصة عقار for total separation of concerns.

  • Entities & Domain: Pure business rules without framework coupling.
  • Use Cases: Application-specific orchestrations and commands.
  • Interface Adapters: Repositories, DTOs, and API controllers.
  • Frameworks & Drivers: Web (Next.js), DB (PostgreSQL), External OTP APIs.
Used for: Complex Enterprise & High-Security Platforms

SOLID Principles

Standard design discipline enforced across Laravel and TypeScript backends.

  • S Single Responsibility: Each service handles one discrete task.
  • O Open/Closed: Extensible modules via strategies and decorators.
  • L Liskov Substitution: Interchangeable repository implementations.
  • I Interface Segregation: Compact, focused contracts for clients.
  • D Dependency Inversion: Code depends on abstractions, not concretions.
Used for: Maintainable, Test-Driven Codebases

MVC & MVVM Patterns

Proven patterns tailored for web controllers and reactive mobile state.

  • MVC: Streamlined HTTP request lifecycle, routing, and controller validation.
  • MVVM: Reactive two-way bindings for Flutter, Kotlin, and React view states.
  • State Isolation: UI re-renders only on immutable state transitions.
  • Mockability: Enables fast unit testing without launching emulator or browser.
Used for: Flutter Mobile & Web Interfaces

Detailed Architecture Breakdown: "رخصة عقار"

Frontend Presentation (Next.js)

Built with Next.js App Router, React Server Components for ultra-fast first-paint, Tailwind CSS for fluid responsive layout, and full Arabic RTL layout support. Integrates client-side validation and interactive permit tracking portals.

Application & Domain (Laravel + SOLID)

Segregated into domain entities, repositories, and use-case service classes. Controllers contain zero business logic. Dependency Inversion ensures SMS providers, PDF generators, and notification buses can be swapped without touching core rules.

Persistence & Security Layer

PostgreSQL ensures high relational integrity with transactional ACID rollbacks. Laravel Sanctum & JWT manage token rotation and role authorization, while SMS OTP gateways verify high-privilege operations.
