## 🌟 #1 Featured Project: رخصة عقار (Rokhsa Aqar)

A digital governmental real estate building permit platform engineered to automate and streamline permit applications, engineering inspections, and digital license issuance.

- **Live URL:** [https://rokhsa-aqar.vercel.app/](https://rokhsa-aqar.vercel.app/)
- **Architecture Highlights:**
  - **Frontend:** Next.js (App Router, React Server Components, Tailwind CSS, Responsive RTL).
  - **Backend:** Laravel 11 with Clean Architecture, Domain-Driven Design (DDD), and SOLID principles.
  - **Database:** PostgreSQL for ACID transactions and spatial indexing.
  - **Security & Auth:** Multi-guard JWT / Laravel Sanctum with Role-Based Access Control (RBAC).
  - **Verification:** Two-factor SMS OTP authentication for secure permit verification and issuance.
